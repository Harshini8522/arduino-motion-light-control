# Arduino-Based Motion Detection Automatic Light Control

## Project Overview
This project uses an Arduino and a PIR (Passive Infrared) motion sensor to detect movement and automatically control a light. It aims to reduce unnecessary power consumption by switching the light according to detected motion.

## Objectives
- Detect movement using a PIR sensor.
- Automatically control a light using Arduino.
- Reduce unnecessary lighting and energy usage.
- Learn sensor interfacing and embedded programming.

## Components Used
- Arduino board
- PIR motion sensor
- LED or light source
- Connecting wires
- Breadboard, if used
- Suitable power supply

## Working Principle
1. The PIR sensor detects movement through changes in infrared radiation.
2. The sensor sends a signal to the Arduino.
3. The Arduino processes the input and controls the light.
4. The light responds according to the programmed conditions.

## Technologies Used
- Arduino
- Embedded C/C++ (Arduino programming)
- PIR motion sensor
- Basic electronics and automation

## Future Enhancements
